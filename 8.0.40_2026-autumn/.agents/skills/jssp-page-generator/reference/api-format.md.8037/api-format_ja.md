# Format API リファレンス

## 概要

Format は、文字列変換を行う静的オブジェクトである。
数値・日付・文字列のフォーマット変換 API を提供する。

## メソッド一覧

| メソッド | 戻り値 | 説明 |
|---------|--------|------|
| `get(format, arg, ...)` | String | 引数値を format 指定にあわせて文字列変換 |
| `fromNumber(format, value)` | String | フォーマット指定に沿って数値を文字列に変換 |
| `toMoney(value)` | String | 3桁カンマ区切り数字列を生成 |

## get(format, arg, ...)

引数値を format 指定に合わせて文字列変換する汎用メソッド。
引数の arg は16個まで指定可能。

### フォーマット指定文字

| 指定文字 | 説明 | 例 |
|----------|------|-----|
| `%s` | 文字列変換 | `%3s` で3バイト |
| `%n` | n進数変換 | `%4n` で4進数 |
| `%d` | 10進数変換 | `%8.3d` で整数8桁・小数点3桁 |
| `%x` | 16進数変換 | `%4x` で4桁0マスク |
| `%b` | 2進数変換 | `%8b` で8桁0マスク |
| `%m` | 3桁カンマ区切り | |
| `%t` | 日付変換 | |
| `%%` | "%" 文字表示 | |

### 使用例

```javascript
// 文字列変換
let result = Format.get('名前は「%4s」です。', 'intra-mart');

// 10進数変換（整数7桁・小数点3桁）
let result = Format.get('金額: %7.3d 円', 1234567.89123);

// 16進数変換
let result = Format.get('16進数: %3x', 55);

// 2進数変換
let result = Format.get('2進数: %4b', 12);

// 3桁カンマ区切り
let result = Format.get('合計: %m 円', 333444555666);

// % 文字の表示
let result = Format.get('達成率: 100%%');
```

## fromNumber(format, value)

数値をフォーマット指定に従って文字列に変換する。

### フォーマット文字

| 文字 | 説明 |
|------|------|
| `0` | 数字表示（ゼロ埋め） |
| `#` | 数字表示（ゼロは非表示） |
| `.` | 小数点位置 |
| `,` | グループ区切り位置 |

### 使用例

```javascript
// カンマ区切り
let result = Format.fromNumber('#,##0', 1234567);
// → "1,234,567"

// 小数点2桁
let result = Format.fromNumber('#,##0.00', 1234.5);
// → "1,234.50"
```

## toMoney(value)

3桁ごとのカンマ区切り数字列を生成する。小数部分は2桁まで表示。

```javascript
let result = Format.toMoney(1234567);
// → "1,234,567"
```
