# 画面定义的结构与说明

生成的画面定义须具备以下结构

1. 画面一览
  - 记载画面一览。
  - 一览的项目包括「画面 ID」「画面定义名」「对应的任务」「URL 路径」「功能概要」等。

2. 画面详情
  - 按画面分别记载以下内容
    - 画面概要
    - 画面项目
    - 画面布局示意图
    - 校验
    - 按钮等操作处理

## 参考技能
- `.agents/skills/jssp-imds-theme/SKILL.md`：符合 imds 规范的 HTML 代码生成
- `.agents/skills/jssp-page-generator/SKILL.md`：JSSP 代码生成支持

## 注意事项
- **原则上画面定义中不创建一览画面（检索业务数据并以列表形式显示结果的画面），仅创建登记・编辑・详情画面。（但若有明确指示，也允许创建一览画面。）**
* **对于登记画面与编辑画面等设计相似的画面，不将页面（展示页面 + 函数容器）拆分。**
  * 在展示页面内通过分支来切换登记时的显示区域与编辑时的显示区域。
