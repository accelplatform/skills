# スクリプト開発モデル概要

> **適用範囲**: 🟢 **常時** — 全ての JSSP 実装で適用。プロジェクト前提・技術スタック理解のため必読。

## 目的

本規約は、intra-mart Accel Platform のスクリプト開発モデルを用いたアプリケーション開発において、コードの品質、保守性、可読性を確保するための標準的なルールを定めるものである。

## 適用範囲

- スクリプト開発モデル（JSSP）を用いたすべての開発プロジェクト
- ファンクションコンテナ（.js）およびプレゼンテーションページ（.html）
- 関連する設定ファイル（ルーティング定義XML等）

## スクリプト開発モデルの構成

スクリプト開発モデルは、以下の2つのファイルで構成される：

| ファイル種別 | 拡張子 | 役割 |
|------------|--------|------|
| ファンクションコンテナ | .js | サーバサイド JavaScript。ビジネスロジック処理を担当 |
| プレゼンテーションページ | .html | 画面表示を担当。IMART タグを使用 |

**実行環境**: Rhino（Java 上で動作する JavaScript エンジン）

## 処理シーケンス

1. リクエスト受信
2. session.js の init() 実行
3. ファンクションコンテナの init() 実行
4. プレゼンテーションページの実行（HTML 生成）
5. session.js の close() 実行
6. レスポンス返却

## 本規約の位置づけ

本規約は推奨事項であり、プロジェクトの特性に応じて適宜調整可能である。
ただし、**セキュリティに関する規約は必須として遵守すること**。
