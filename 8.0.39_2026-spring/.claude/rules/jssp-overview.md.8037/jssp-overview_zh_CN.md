# 脚本开发模型概述

> **适用范围**: 🟢 **始终** — 适用于所有 JSSP 实现。理解项目前提与技术栈所必读。

## 目的

本规约旨在通过使用 intra-mart Accel Platform 脚本开发模型进行应用程序开发时，制定确保代码质量、可维护性和可读性的标准规则。

## 适用范围

- 使用脚本开发模型（JSSP）的所有开发项目
- 函数容器（.js）和展示页面（.html）
- 相关配置文件（路由定义 XML 等）

## 脚本开发模型的结构

脚本开发模型由以下两个文件构成：

| 文件类型 | 扩展名 | 作用 |
|---------|--------|------|
| 函数容器 | .js | 服务端 JavaScript，负责业务逻辑处理 |
| 展示页面 | .html | 负责画面显示，使用 IMART 标签 |

**运行环境**：Rhino（在 Java 上运行的 JavaScript 引擎）

## 处理顺序

1. 接收请求
2. 执行 session.js 的 `init()`
3. 执行函数容器的 `init()`
4. 执行展示页面（生成 HTML）
5. 执行 session.js 的 `close()`
6. 返回响应

## 本规约的定位

本规约为推荐事项，可根据项目特性进行适当调整。
但是，**与安全相关的规约为必须遵守项**。
