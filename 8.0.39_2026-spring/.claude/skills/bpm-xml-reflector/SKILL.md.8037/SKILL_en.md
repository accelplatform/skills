# BPMN-XML Specification / Script Content Reflection Skill

## Purpose
A skill set for reflecting into BPMN-XML the matters required to operate on IM-BPM.
It reflects into BPMN-XML the content of specification documents created using `bpm-docs-generator`.
It reflects into BPMN-XML the content of scripts generated using `bpm-scripts-generator`.

## File Structure

```
bpm-xml-reflector/
├── SKILL.md                            # This file
├── scripts/
│   ├── bpmn-scripts-reflector.js  # Various functions for reflecting generated script content into BPMN
│   ├── bpmn-specs-reflector.js         # Various functions for reflecting specification content into BPMN (ID replacement verification is also possible via CLI execution)
│   └── bpmn-reflector-utils.js         # Utility functions shared by the two files above
└── reference/
    ├── bpmn-scripts-reflector.md       # Specification for reflecting the content of script-generated artifacts into BPMN XML
    └── bpmn-specs-reflector.md         # Specification for reflecting the content of specification documents into BPMN XML
```
