# Debug API リファレンス

## 概要

Debug は、開発中のデバッグ時に利用するオブジェクトである。
変数情報をブラウザ、コンソール、ファイルに出力する機能を提供する。
static メソッドのみで構成されており、インスタンス化せずに直接利用できる。

## メソッド一覧

| メソッド | 説明 | 出力先 |
|---------|------|--------|
| browse(arg, args...) | 変数情報をブラウザ画面に表示 | ブラウザ |
| console(arg, args...) | オブジェクト内容を JSON 形式でコンソールに表示 | コンソール |
| print(msg) | メッセージをコンソールに出力 | コンソール |
| write(msg) | メッセージをファイルに出力 | debug.txt |

## メソッド詳細

### browse(arg, args...)

変数情報をブラウザ画面に表示する。

| パラメータ | 型 | 説明 |
|-----------|------|------|
| arg | Object | 表示対象の変数 |
| args... | Object | 追加の変数（任意個数） |

- あらゆる JavaScript 変数型を指定可能
- **実行後、以降のプログラムは実行されない**
- try...catch 文では使用不可

### console(arg, args...)

オブジェクト内容をコンソール上にJSON形式で表示する。

| パラメータ | 型 | 説明 |
|-----------|------|------|
| arg | Object | 表示対象の変数 |
| args... | Object | 追加の変数（任意個数） |

- JSON 形式で出力されるため、出力内容をソースにコピーしてオブジェクト化が可能
- JSON 形式として不正なプロパティは表示されない

### print(msg)

コンソールへメッセージを出力する。

| パラメータ | 型 | 説明 |
|-----------|------|------|
| msg | String | 出力するメッセージ |

### write(msg)

ファイルへメッセージを出力する。出力先はホームディレクトリ直下の `debug.txt`（標準設定では `WEB-INF/debug.txt`）。複数呼び出し時は追記モードで動作する。

| パラメータ | 型 | 説明 |
|-----------|------|------|
| msg | String | 出力するメッセージ |

## 使用例

### コンソールへのデバッグ出力

```javascript
let sampleObject = {
  'property1': '文字列1',
  'property2': new Date(),
  'property3': 256
};
Debug.console(sampleObject);

Debug.print('処理開始');
```

### ファイルへのデバッグ出力

```javascript
Debug.write('変数値: ' + value);
```

### ブラウザへの変数表示

```javascript
// 注意: 以降のプログラムは実行されない
Debug.browse(request, response);
```
